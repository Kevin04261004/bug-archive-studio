# Bug family art direction

Keep the established fluorescent lime bug family and polished chibi anime finish.
Each compiler error gets one readable visual motif; keep the shape cute at small sizes.

- Rounded soft body, large dark oval eyes, tiny feet, expressive antennae.
- Fluorescent lime primary color; a restrained secondary accent is optional.
- A clear error-related motif: CS1002 has a semicolon marking.
- Future bugs can have rounder cheeks, shorter antennae, playful poses or small accessories.
- Preserve a friendly collector-world look. Avoid scary anatomy and dense mechanical detail.
- One centered bug, entirely visible, with actual transparent alpha and a small clear margin.
- No caption, card, error number or UI baked into the image; the renderer supplies them.

The studio builds this prompt for you. `Generate bug with AI` in index.html fills in the error concept,
one motif per error code, and exactly one variation from the list above, then sends the CS1002 image as a style reference.

Example image prompt:
"Create one adorable fluorescent lime chibi bug for the Bug Archive family, inspired by [ERROR CONCEPT]. Round soft body, oversized black oval eyes, tiny feet, expressive antennae, [ONE ERROR MOTIF]. Match the established CS1002 bug illustration. Single centered isolated character, genuine transparent PNG, no text, no card, no background."
